PYTHON NUMBER PROGRAMS - 40 SEPARATE FILES

HOW TO USE
1. Extract this ZIP file.
2. Open VS Code, choose File > Open Folder, and select Python_Number_Programs.
3. Open Terminal > New Terminal.
4. Run any file, for example:
   python 01_check_even_or_odd.py
5. Enter the requested number(s) in the terminal and press Enter.

Requires Python 3. No extra packages are required.
If Python is available through the Windows py launcher, use py instead of python.

NOTES
- Each .py file runs independently and accepts keyboard input.
- Enter integers, not decimal numbers or words.
- Digit operations ignore the minus sign. Zero has one digit: 0.
- Reversing and removing the last digit preserve a negative sign.
- Leading zeros are not retained: reversing 1200 gives 21.
- Negative numbers are not palindromes in these programs.
- Armstrong, strong, automorphic and neon checks accept non-negative integers.
- Perfect and prime numbers must be positive; primes start at 2.
- Leap years use Gregorian rules and require a positive year.
- The multiplication table runs from 1 to 10.
